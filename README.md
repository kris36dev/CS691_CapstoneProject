# Unity Game Capstone
### Product definition · System design · Team delivery

An academic team project documenting the path from user needs and architecture to sprint reviews and a recorded game demonstration.

[Watch the demo](Artifacts/demo%20vedio.mp4) · [Read the technical paper](Artifacts/Technical%20paper/The%20Great%20Escape%20Technical%20Paper.pdf) · [View final presentation](Artifacts/Slides/Sprint3-slides.pdf)

## Executive summary

This repository collects the project artifacts for a Unity game capstone: product personas, user stories, architecture diagrams, sprint materials, and deployment guidance.

Its clearest contribution as a portfolio case is the documented delivery process—how a team organizes a product concept into requirements, design artifacts, and reviewable milestones. The materials describe academic work; they do not establish commercial adoption or business impact.

## Repository scope

This checkout is an **artifact portfolio**, not a complete runnable Unity project. It does not contain the standard Unity source-project folders. The file named `Game` is a short text note, not an executable or project download.

The original sprint records are retained for context; some links in those historical documents point to the original team repository.
